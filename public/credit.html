Credits & References

Resources, libraries, assets and references used in the development of ShiokLah!.

Libraries & Frameworks

  • Chart.js - Used to create interactive charts and visualise dashboard data such as sales performance and analytics.
  • Express.js - Used as the backend web framework to create API routes, handle HTTP requests, and manage server-side logic.
  • Microsoft SQL Server - Used as the relational database management system to store and manage application data.
  • Node.js - Used as the JavaScript runtime environment for developing the backend server application.
  • Joi - Used for validating user input and ensuring submitted data follows the required format and rules.
  • bcrypt - Used for securely hashing and verifying user passwords during authentication.
  • express-session - Used for managing user session data and maintaining login states.
  • JSON Web Token (JWT) - Used for secure user authentication and authorisation between the client and server.
  • Jest - Used for testing backend functions and ensuring application logic works correctly.
  • Swagger / OpenAPI - Used to document and test API endpoints for easier backend development and integration.

AI Assistance

  • ChatGPT (OpenAI) - Used for programming assistance, debugging support and UI improvement suggestions.
